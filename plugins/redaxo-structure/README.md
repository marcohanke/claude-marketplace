# redaxo-structure

Claude Code support for REDAXO's Structure addon – articles, categories, and the content tree.

## Skills

- **structure-articles** – `rex_article` API, getting/listing articles, status, dates
- **structure-categories** – `rex_category` API, tree traversal, navigation queries
- **structure-content** – slices, content editing via API, programmatic content management
- **structure-meta-info** – custom fields on articles/categories, the meta_info plugin

## Install

```bash
/plugin install redaxo-structure@redaxo-marketplace
```

The Structure addon is part of the REDAXO core and always installed on a working REDAXO instance.
